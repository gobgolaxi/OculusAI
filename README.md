# OculusAI

**Сайт и панель: [oculusai.space](https://oculusai.space/)** · [Релизы](https://github.com/gobgolaxi/OculusAI/releases)

Античит для Paper, который оценивает аим нейросетью, а не фиксированными порогами.
Плагин режет бой на окна, считает по ним признаки и отправляет их в сервис, а тот
возвращает вероятность чита. Из вероятностей копится буфер: по одному порогу
уходит алерт, по другому — наказание.

## Установка

1. Paper (или форк) 1.16.5+ и ProtocolLib.
   На Folia работает анализ, алерты и наказания; голограммы, манекен,
   тестовая арена и слежка за игроком там отключаются — каждая из них
   читает сущности через границу региона, чего Folia из одного потока
   не разрешает.
2. Положить jar и ProtocolLib в `plugins/`, запустить сервер.
3. Написать `/oai connect` на сервере и открыть выданную ссылку под своим аккаунтом —
   ключ и IP сервера пропишутся сами. Аккаунт и бесплатный Pro на 3 дня —
   на [oculusai.space](https://oculusai.space/).
4. `/oai guide` в игре — короткая инструкция.

`api.url` по умолчанию указывает на публичный сервис, менять его нужно только
ради своего инстанса.

Вместе с настройками плагин сообщает сервису два числа — сколько игроков на
сервере и сколько из них анализируется прямо сейчас. Они нужны для счётчика
«под наблюдением» на [oculusai.space](https://oculusai.space/); ники, адреса и
что-либо ещё про игроков в этот отчёт не попадают.

Ключ можно вписать и руками в `api.key`, тогда IP сервера нужно указать в панели самому:
без адреса ключ не работает.

## Команды

| Команда | Что делает |
|---|---|
| `/oai connect` | привязать сервер к аккаунту одной ссылкой |
| `/oai guide` | как пользоваться античитом, в один экран |
| `/oai monitor` | следить за всеми в пвп, строки видит только включивший (повтор - выключить) |
| `/oai monitor list` | живой список подозрительных |
| `/oai prob <ник>` | следить за одним игроком |
| `/oai math` | переключить Prob между сглаженным и чистым показанием модели (буфер не трогает) |
| `/oai bypass <ник>` | выключить или снова включить античит для игрока |
| `/oai history <ник>` | прошлые показания, хранятся на диске |
| `/oai journal` | журнал сработок |
| `/oai player <ник>` | буфер и история игрока |
| `/oai forget <ник>` | сбросить подозрение |
| `/oai npc` | манекен-спарринг для проверки |
| `/oai data` | запись обучающих данных |
| `/oai diag [ник]` | почему окна игрока анализируются или нет |
| `/oai dashboard` | меню настроек |
| `/oai update` | проверить, вышла ли новая версия |
| `/oai reload` | перечитать конфиг |

Права: `oculusai.command`, `oculusai.alerts`, `oculusai.journal`, `oculusai.data`,
`oculusai.npc`, `oculusai.connect`, `oculusai.diag`, `oculusai.bypass`, `oculusai.report`.

Про новую версию плагин сам пишет в чат тем, у кого есть `oculusai.alerts`, и
повторяет это каждые 15 секунд, пока сервер сидит на старой сборке
(`update.remind-seconds` в конфиге — интервал, `0` — сказать один раз).

## Сборка

```
./gradlew shadowJar -PmcVersion=1.16.5
./gradlew shadowJar -PmcVersion=1.21.11
```

Версии 1.16.x собираются в байткод Java 16 — Commodore на этих серверах не читает
ничего новее. Версии 1.21.x собираются под Java 21. Версионный код лежит в
`src/v116` и `src/v121`, общий — в `src/main`.
